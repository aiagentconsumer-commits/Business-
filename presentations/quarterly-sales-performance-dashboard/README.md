# Quarterly Sales Performance Dashboard

A 10-page standalone HTML presentation for quarterly sales performance reviews.

## Open the deck

Open `cover.html` in a browser, then navigate through the slide files in this order:

1. `cover.html`
2. `exec_snapshot.html`
3. `revenue_trend.html`
4. `pipeline_health.html`
5. `win_loss.html`
6. `product_mix.html`
7. `regional_perf.html`
8. `trend_analysis.html`
9. `actions.html`
10. `appendix.html`

The slides are authored at 1280×720 and use Chart.js plus Google Fonts from approved CDNs.

## Data note

All figures are explicitly labeled **FY2026 SAMPLE DATA** and are illustrative for dashboard demonstration. Replace the data arrays and narrative text with the organization’s CRM / sales-operations export before using this in an executive or external setting. The appendix includes field-mapping guidance.

## Contents

- Revenue growth and plan attainment
- Pipeline coverage, stage mix, and aging
- Win/loss rates and loss reasons
- Product mix, growth, and margin
- Regional revenue and attainment
- Cross-metric trend analysis
- Strategic actions and metric definitions
